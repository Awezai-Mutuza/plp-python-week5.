
# Week 5 Assignment: Password Generator & Your Own Module

## Project Files

- `password_generator.py` - Generates random passwords using Python's random and string modules.
- `helpers.py` - Contains functions for calculating the number of tables needed and welcoming users.
- `main.py` - Imports the helpers module and tests its functions.

## What I Learned

I learned how to import Python modules, generate random passwords, use math.ceil() to round up calculations, and create my own module with reusable functions.
